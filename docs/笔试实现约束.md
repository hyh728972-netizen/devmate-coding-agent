# 笔试实现硬约束

本项目必须满足以下硬约束，否则直接视为不合格：

1. `Coding Agent` 必须基于 **最新稳定版** `deepagents` 和 **最新稳定版** `langchain` 实现。
2. 不接受 `langchain 0.3.x` 或其他旧范式的手写 agent loop 作为主实现。
3. 主执行入口必须使用官方推荐 API：
   - 复杂 Coding Agent 场景优先使用 `deepagents.create_deep_agent`
   - 简单 agent 场景才考虑 `langchain.agents.create_agent`
4. Skills 必须遵循 Deep Agents 官方 `SKILL.md` 目录规范，不接受自定义 JSON 技能格式作为主实现。
5. 模型接入必须兼容 LangChain 当前官方模型初始化方式，并优先使用 `provider:model` 形式配置。
6. 如果项目实现与上述约束偏离，即使功能可运行，也不能视为通过。

当前仓库整改目标：

- Agent 主运行时切换到 `create_deep_agent`
- Skills 切换到 `skills/<skill-name>/SKILL.md`
- 保留 RAG、本地工作区和联网搜索能力
- 继续使用 Python 3.13、`uv`、`config.toml`
